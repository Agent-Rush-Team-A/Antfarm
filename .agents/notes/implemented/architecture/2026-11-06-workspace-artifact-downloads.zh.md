# Agent Note: 固定描述符的工作区下载

Status: implemented

[English](2026-11-06-workspace-artifact-downloads.md) | 中文

## Problem

工作区进程可能在路径检查与打开之间替换路径。浏览器下载不能暴露授权工作区外的文件；关闭沙箱后，保留的任务产物仍需可访问。

## Decision

[产物插件](../../../../packages/api/workspace-artifacts/README.zh.md)独立提供以工作区标识寻址的只读能力。每个目录通过父目录描述符打开；所有组成部分均拒绝符号链接，最终已打开的描述符必须为普通文件。登记根目录的父目录必须可信。每个 chunk 读取前后复查下载权限与工作区登记。

下载保留已打开 inode 的初始字节范围，通过认证 HTTP 流传输。请求及响应流在描述符清理完成前都有明确所有者；插件撤下时取消并等待二者结束。浏览器缓冲时执行部署上限，只保存完整接收的 Blob。

现有预览服务仍遵循[会话预览读取权限决策](2026-09-09-workspace-file-read-authority.zh.md)。产物能力使用工作区范围约束和归属授权，不继承较宽的会话文件系统读取策略。[上传发布决策](2026-11-05-workspace-upload-publication.zh.md)继续负责写入。

## Alternatives considered

解析路径并检查前缀后再普通打开，会与路径替换竞争。允许符号链接需要更强的内核路径解析支持；此插件拒绝符号链接并固定每个目录。复用预览端点会继承其工作区外读取策略。

把 URL 直接交给浏览器下载管理器，应用无法可靠获得失败结果。有上限的完整 Blob 能报告权限、大小和传输失败，且不保存不完整的文件。

## Consequences

需要 Linux 描述符路径和可信工作区父目录。符号链接与特殊文件被省略。列表有上限并手动刷新；下载具有可配置字节上限，不提供文件系统快照、预览、备份或恢复。沙箱生命周期独立。

确定性替换测试覆盖目录替换、打开前文件替换及打开后路径替换。真实 Connection 测试覆盖授权与未消费响应流的卸载；真实 Web 验收覆盖双账号、部署前缀和容器退出后保留的文件。
